# Omnifood Landing Page

โปรเจกต์ฝึกฝนการสร้างเว็บไซต์ Landing Page สำหรับบริการจัดส่งอาหารเพื่อสุขภาพ  
โดยเน้นการฝึกพื้นฐาน HTML, CSS, Responsive Web Design และการจัดวาง Layout

---

## 🎯 Purpose of This Project

โปรเจกต์นี้จัดทำขึ้นเพื่อฝึกทักษะ Front-end พื้นฐาน หลังจากเรียน HTML และ CSS

สิ่งที่ผมได้ฝึกจากโปรเจกต์นี้ ได้แก่:

- การเขียนโครงสร้างเว็บไซต์ด้วย HTML
- การจัดรูปแบบหน้าเว็บด้วย CSS
- การจัดวาง Layout ด้วย Flexbox
- การจัดวาง Layout ด้วย CSS Grid
- การทำ Responsive Design
- การใช้ Media Queries
- การจัดองค์ประกอบเว็บไซต์ให้เหมาะกับหน้าจอหลายขนาด

---

## ✨ Features

- Landing Page สำหรับบริการจัดส่งอาหารเพื่อสุขภาพ
- Hero Section
- Features Section
- Meal / Product Cards
- Testimonials
- Pricing Section
- Call-to-Action Section
- Responsive Navigation
- รองรับ Desktop, Tablet และ Mobile

---

## 🛠 Technologies Used

- HTML
- CSS
- Flexbox
- CSS Grid
- Media Queries
- Responsive Web Design
